# Model Card — PPI Radar Target Detector CNN

## Model summary

A fully-convolutional neural network (FCN) that detects moving point targets in
synthetic rotating-radar (PPI) data. Takes three temporal feature channels derived
from 10 consecutive radar sweeps and outputs a per-cell detection probability map.

| Property | Value |
|----------|-------|
| Architecture | 5-layer FCN (Conv2d 3×3, stride 1, padding 1, no pooling) |
| Input | (1, 3, 180, 64) — batch × channels × azimuths × range bins |
| Output | (1, 180, 64) — per-cell sigmoid probability map |
| Parameters | ~19 000 |
| ONNX opset | 17 |
| Inference (CPU) | < 10 ms per scan |

## Input features

All three channels are derived from N=10 radar sweeps and whitened by the
per-range 10th-percentile clutter floor before being passed to the network:

| Channel | Description |
|---------|-------------|
| Max | Pixel-wise maximum over all sweeps — captures peak target illumination |
| Mean | Pixel-wise mean — provides the clutter baseline |
| Std | Pixel-wise standard deviation — high where amplitude varied (motion fingerprint) |

## Training data

- **Source:** Synthetic PPI sequences generated by `src/data/ppi_generator.py`
- **Dataset:** 800 training / 200 validation samples (50 % target, 50 % clutter-only)
- **SNR range:** −20 to +40 dB (uniform draw per sample)
- **Target parameters:** range bin 10–54, azimuth 0–360°, radial velocity ±3 bins/sweep,
  tangential velocity ±4 °/sweep
- **Clutter model:** Range-dependent Rayleigh (σ = r/R_max), no sea/land Weibull model
- **Seed:** 42 (reproducible)

## Known limitations and failure modes

- **Stationary targets:** The std feature is low for a stationary target; the model
  is trained on moving targets only and will underperform on slow or hovering objects.
- **Multiple simultaneous targets:** The model was trained with at most one target per
  frame; performance with multiple targets is not characterised.
- **Clutter model mismatch:** Training uses Rayleigh clutter only. Sea clutter (K or
  Weibull distribution) or land clutter will cause elevated false-alarm rates.
- **No Doppler processing:** Radial velocity is a scene parameter, not a measured
  Doppler output. The model does not exploit coherent phase information.
- **No antenna pattern:** Uniform azimuth illumination is assumed. Real beam roll-off
  and sidelobes will cause range-varying SNR that the model has not seen.
- **Short observation window:** Fixed at 10 sweeps. Performance degrades if fewer
  sweeps are available or if the antenna rotation rate changes.

## Intended use

Demonstration and benchmarking of ML-based radar detection against classical
CA-CFAR and Kalman-filter tracking on synthetic PPI data. Not validated for
operational deployment without further testing on real sensor data.

## Deployment

```bash
# Build and run
docker build -t ppi-radar-demo .
docker run -p 8501:8501 ppi-radar-demo
```

The ONNX model (`artifacts/ppi_model.onnx`) can be loaded with any ONNX Runtime
≥ 1.18 and integrated into existing radar processing pipelines.
